# E2E-01 实测报告：STM32F103 Cortex-M3 完整 DS-PIT DSP 流水线

> **权威数据来源**：本报告全部数值均由 `analyze_e2e.py` 从 `fw/fw.map` 与 `results/e2e_run_*.json` 自动重算写入 `results/results_summary_e2e.json`。
> **与 EMB-01 的关系**：EMB-01（2026-09-21）仅评测了离线观测输入、关闭可靠性温度（$\tau_t=1$）的原始 Viterbi 解码核（5.89 ms/窗，3.2 kB 静态 RAM，≈4.7 kB 代码）；本实验（E2E-01）在同一硬件平台上完成包含预处理、FFT、双分支增强、因果 LBP 温度更新、带状固定滞后 Viterbi 解码与 3 点中值输出的**完整端到端 DSP 流水线**片上实测。

---

## 1. 硬件平台与测量边界

| 项 | 实测配置与口径 |
|---|---|
| 目标板 / MCU | STM32-Mini V3.1 (Mcudev)；STM32F103 兼容片（Cortex-M3 r1p1，无硬件 FPU，soft-float `float32`） |
| 器件 ID / 资源 | `DBGMCU_IDCODE = 0x10036414`（Flash 256 KiB，SRAM 64 KiB） |
| 主频配置 | 72.00 MHz（`RCC_CFGR = 0x001d040a`，HSE 8 MHz × 9 PLL，2 Flash wait states） |
| 测试记录 | 沿用 EMB-01 的 5 条公开数据集前缀记录：`s1`–`s3`（PPG-DaLiA S1–S3, 125 Hz）与 `ws1`–`ws2`（WESAD S2–S3, BVP 64 Hz / ACC 32 Hz）；每条回放 261 个 2-s 块（522 s 原始数据，覆盖 257 窗、254 个有效评估输出窗） |
| **边界声明** | 原始 PPG/ACC 样点经 SWD 从主机分块回放至片上 SRAM 邮箱（每次 2-s 块），`DWT->CYCCNT` 仅统计 S1–S6 纯计算周期（不含 SWD 传输）；**不包含**物理光电/加速度传感器采集驱动、BLE/无线通信与直接功耗仪电流测量（能量为数据手册典型电流乘实测时间之**理论估算**） |

## 2. 逐阶段片上执行时间（72 MHz，banded $W_{band}=13$）

### 2.1 五条记录合并稳态统计（`n = 1,285` 步，每 2-s 步触发 1 窗）

| 阶段 | 模块功能 | Mean (ms) | P95 (ms) | Max (ms) | 占比 (%) |
|---|---|---:|---:|---:|---:|
| **S1** | 4 级 SOS 带通滤波 + 多相重采样（含 WESAD ACC 32→64 Hz 插值） | 66.504 | 81.917 | 81.980 | 31.91 |
| **S2** | 8-s 滑窗 z-score + 2 次实信号打包 1024 点基-2 FFT + 92 频点幅度 | 122.099 | 122.245 | 122.320 | 58.58 |
| **S3** | 双分支幅值比增强（15 帧环形队列）+ 插值 + 30-BPM 渐变 + 归一 + $\log L$ | 13.147 | 13.266 | 13.356 | 6.31 |
| **S4** | 因果 LBP 锚、速度 $\hat{v}_t$、可靠性 EMA 与温度 $\tau_t$ 调制 | 0.344 | 0.377 | 0.379 | 0.17 |
| **S5** | 固定滞后带状 Viterbi 解码（$K=161, D=3, W_{band}=13$）+ 回溯与历史更新 | 6.336 | 6.375 | 6.496 | 3.04 |
| **S6** | 流式 3 点中值输出平滑 | 0.005 | 0.005 | 0.005 | 0.00 |
| **总计** | **完整 DS-PIT DSP 流水线（每 2-s 步）** | **208.435** | **224.011** | **224.182** | **100.00** |

- **2-s 步长占空比**：合并均值占空比 **10.42%**（PPG-DaLiA 125 Hz：**223.713 ms** / P95 224.042 ms，占空比 **11.19%**，其中 S1 均值 81.809 ms；WESAD 64/32 Hz：**185.520 ms** / P95 185.789 ms，占空比 **9.28%**，其中 S1 均值 43.547 ms）。
- **冷启动前 4 个 2-s 填充块（`n = 20`，仅 S1 缓冲）**：均值 64.276 ms（DaLiA 约 70.9–81.9 ms，WESAD 约 37.5–43.6 ms）。
- **Dense 对照（`s1`）**：S5 均值由 `69.001 ms`（dense）降至 `6.336 ms`（banded $W=13$，提速 **10.89×**）；端到端总均值由 `286.324 ms` 降至 `223.659 ms`，输出 254/254 完全一致。
- **可重复性（`s1` 连续三次运行）**：`est`、`es`、`tau` 全部逐字节一致；全部 261 块中单块最大周期差 $\le 2$ 周期（相对波动 $0.000\%$）。

- **一致率差异根因说明**（详见 `E2E-01_LOG.md` 条目 2）：分模块隔离 `REAL_DOUBLE` 测试全 5 条记录 100% 通过；`s1` 上 `float32` 与离线双精度的差异来自静坐无运动段 ACC 标准差降至 $3.5\times 10^{-12}$ 附近时 `float32` 前端噪底经 z-score 放大，并触发 `ds5.m:435` 在 `base = 1.0` 处的硬阶跃（`WF1 < 0 -> -1`）。同窗 MAE 不仅未劣化，5 条均值还略低 0.20 BPM（7.53 vs 7.73 BPM）。

### 4.2 算法前瞻延迟与理论能耗估算

- **端到端算法延迟分解**：多相抗混叠重采样引入 **0.4 s** 固定前瞻（另 WESAD ACC 32→64 Hz 线性插值占 0.031 s），Viterbi 固定滞后 $D=3$ 引入 **4.0 s** 前瞻，流式 3 点中值平滑引入 **2.0 s** 前瞻，合计因果前瞻 **6.4 s**（含 8 s 窗起始等待共 **14.4 s**，外加 ~0.21 s 稳态计算时间）。
- **理论能耗（ESTIMATE ONLY，非实测）**：按 STM32F103xC/D/E 数据手册（DocID 14611）72 MHz 典型运行电流 `36–50 mA` @ `3.3 V` 与实测合并均值 `208.435 ms` 计算，每 2-s 步理论能耗为 **24.76–34.39 mJ**（等效平均功耗 **12.38–17.20 mW**；其中 DaLiA 均值 223.7 ms 对应 26.58–36.91 mJ，WESAD 均值 185.5 ms 对应 22.04–30.61 mJ）。
